# 🧠 Information presentation

Apply the rules in this section to **every user-facing message** (including progress updates) and to **every human-readable text artifact** the agent creates, edits, or reviews: Markdown, documentation, PRs, tickets, code explanations, website copy, messages, and other writing. Apply them directly from this always-loaded guidance; do not depend on selecting a skill for routine replies. When available, use the information-design skills for deeper work, not as a prerequisite for these rules.

Apply the child dimensions together. Adapt their formatting to the medium and preserve required machine-readable formats, exact quotations, and user-requested layouts.

When an artifact is machine-consumed but also human-reviewed, preserve human navigation and review affordances unless they materially conflict with correct machine behavior. Agent-oriented optimization does not justify making the artifact harder for a human to inspect.

When creating, editing, or reviewing a Markdown file, apply the `format-markdown` skill when available before handoff.
