# 🐚 Mac shell setup

One command installs Homebrew (if needed), chezmoi, shell dependencies, Oh My Zsh, and VS Code, then applies the shared zsh configuration. Personal Macs also install Bitwarden Secrets Manager CLI and enable LangSmith. Professional Macs include neither integration.

## 🚀 Set up a Mac

Run in Terminal on a personal Mac:

```sh
export GITHUB_USERNAME="ArthurZakirov"
/bin/bash -c "$(curl -fsSL "https://raw.githubusercontent.com/${GITHUB_USERNAME}/dotfiles/HEAD/scripts/run_bootstrap.sh")" -- personal
```

For a professional Mac, replace the final `personal` with `professional`. `GITHUB_USERNAME` is the only repository identity the script needs: chezmoi resolves it as GitHub's `<username>/dotfiles` convention. Fresh clones follow the remote's HEAD. To explicitly choose a branch, set `DOTFILES_BRANCH` before running the script.

The download command becomes available once this setup is merged into the default branch. Until then, run the [local bootstrap script](scripts/run_bootstrap.sh) from a checkout containing this setup:

```sh
/bin/bash scripts/run_bootstrap.sh personal
```

macOS may request your administrator password or approval to install Command Line Tools. Bitwarden authentication is a separate, one-time step on personal Macs; the shell starts normally before the Keychain entry exists. The installer preserves existing zsh/config files in a timestamped backup and prints its location. Open a new terminal after installation.

The setup covers the shell and editor, not all workstation applications. Raycast shortcuts and the `sync-systemsmith` helper are optional existing integrations; their external tools are not installed here. Oh My Zsh uses the revision in [chezmoi data](home/.chezmoidata.toml) on every Mac; the setup stops rather than overwriting tracked local changes if alignment is needed.

## 🔄 Keep Macs consistent

The [shared zsh template](home/dot_zshrc.tmpl) defines the prompt, history, completion, Git helpers, fzf, and plugin loading. The root [Brewfile](Brewfile) declares the required Homebrew packages. The [installation hook](home/run_before_10-install-shell.sh.tmpl) is a small entry point that calls the [shell setup module](src/shell-setup.sh). Packages follow Homebrew versions; this is a repeatable setup, not a locked package snapshot.

The [personal template](home/.chezmoitemplates/personal.zsh) is included only when `profile = "personal"`. Your profile and Bitwarden Keychain account are machine-local values generated by the [configuration template](home/.chezmoi.toml.tmpl); credentials stay outside Git. To choose a different Keychain account after setup, run `chezmoi init --prompt` and answer the prompts.

To edit shared settings:

```sh
chezmoi edit ~/.zshrc
chezmoi diff
chezmoi apply
chezmoi git -- add .
chezmoi git -- commit -m "Update shared shell configuration"
chezmoi git -- push
```

On another configured Mac, run `chezmoi update` to pull and apply committed changes. This is explicit synchronization, not background synchronization. `chezmoi apply` also checks dependencies without upgrading existing packages. Use Homebrew to upgrade tools deliberately.

To see the active configuration and managed scope:

```sh
chezmoi source-path
chezmoi managed
chezmoi execute-template '{{ .profile }}'
```

Only zsh and its installation hook are managed. Optional machine-local additions can go in an untracked `~/.zshrc.local`; settings intended to follow a profile should go in the tracked templates.

## ✅ Validation

Run the profile checks with:

```sh
./tests/run.sh
```

The test runner checks script syntax and bootstrap input validation, then renders both profiles, checks that personal integrations are absent from the professional profile, and exercises interactive shell initialization without accessing secrets. The same runner is used by macOS CI. Full fresh-Mac installation still depends on macOS permissions and network access.
